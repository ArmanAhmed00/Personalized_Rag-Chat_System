# Outlawz

Chat with your own documents on your own computer. Outlawz reads PDFs, EPUB ebooks and CSV
spreadsheets, answers questions using only those documents, and links every claim to the exact
passage behind it. Numbers about spreadsheets are computed with pandas, not guessed.

```
pipx install outlawz
outlawz start
```

- Local-first and private: no accounts, no cloud services, no telemetry.
- Works on ordinary laptops (8 GB RAM, no GPU) with a local model through Ollama.

Full documentation: https://github.com/ArmanAhmed00/Personalized_Rag-Chat_System
